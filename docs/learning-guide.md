# Learn through the implemented project

Read in order, then run and explain the corresponding flow:
1. lessons/01-architecture.md - initial design (historical folder scaffold).
2. lessons/02-javascript-node.md - language concepts (historical sample files removed).
3. lessons/03-first-backend.md - first endpoint checkpoint; setup has since expanded, so use README for current commands.
4. lessons/04-authentication-walkthrough.md - database, authentication, authorization, refresh, UI, and tests.

Python bridge: JavaScript objects resemble dictionaries, async/await represents asynchronous operations, TypeScript adds compile-time checks, Express handlers resemble request-processing functions, Prisma queries map operations to SQL tables, and React state controls rendered UI.

Do not try to memorize all files. Follow one request from browser to handler to service to database, then trace its response. Change one thing and re-run the relevant check. Use disposable accounts and never put passwords or tokens in notes.
